# Sementara itu di Malaysia

A one-page timeline of famous American moments from 1776 to 1986, each paired with what was happening in Tanah Melayu and Malaysia at the same time.

Plain HTML, no build step. Open `index.html` or serve the folder.

## Sources

- Event facts and dates: English Wikipedia. Each card links to its article.
- Photos: Wikimedia Commons.
- Movie posters: low-resolution copies from English Wikipedia, used to identify each film.
